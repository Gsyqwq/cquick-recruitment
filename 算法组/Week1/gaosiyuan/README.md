4. 关键参数及分析记录

任务一：图像基础操作

· 缩放：使用 cv2.resize(img, (500, 400)) 将原图强制缩放至 500x400 尺寸。
· 裁剪：利用 Numpy 数组切片 img[100:500, 150:400] 截取图像中心区域。
· 灰度转换：使用 cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)，图像通道数由 3 变为 1。
· 验证：代码中加入了 if im1 is not None and im2 is not None 逻辑，确保了保存到 outputs 文件夹的图片能被重新读取，证明保存成功。

任务二：预处理对比

· 滤波对比：采用高斯滤波 (5, 5)。对比原灰度图，滤波后的图像去除了高频噪点，表面变平滑，但目标边缘出现了一定程度的模糊。
· 阈值分割：对比了阈值 80 和 150。阈值设为 80 时，大量暗色背景被误判为白色目标；调高至 150 时，能较好地分离明亮目标，但目标暗部丢失。
· Canny边缘检测：对比了 (50, 150) 与 (100, 200)。低阈值提取的边缘极多，包含大量噪点纹理；高阈值提取的边缘非常干净，但部分较弱边缘出现了断裂现象。
· 形态学应用：
  · 开运算（先腐蚀后膨胀）：针对阈值图背景中的孤立的白色小噪点，开运算成功将其消除，保持了主目标大小不变。
  · 闭运算（先膨胀后腐蚀）：针对 Canny 边缘图中断裂的线条，闭运算成功将断开的轮廓线连接了起来，有利于后续闭合区域的提取。

任务三：颜色目标提取与轮廓定位

· 测试对象：橘子果肉（橙色）。
· HSV范围设置依据：
  · 由于绿色果皮和背景白墙的干扰，H（色调）设定为 [5, 22]。
  · 为了排除白色橘络和反光高光点，S（饱和度）下限提高到了 100。
· 面积阈值依据：完整的橘子果肉轮廓面积通常在 3000 像素以上，而反光噪点面积通常小于 200，因此将 contourArea 过滤阈值设定为 1000，既能滤除噪点，又不会漏掉小果肉。

5. 失败案例与改进思路（核心分析）

在任务三对橘子图进行提取时，遇到了两个典型问题，并进行了针对性改进：

失败案例 1：高光与橘络导致的掩膜“空洞”

· 现象：生成的 mask.png 中，每块橘子果肉的中心都有黑色的空洞区域。
· 原因分析：果肉中心白色的橘络及表面的强烈反光点，导致其饱和度（S）和明度（V）急剧升高或降低，超出了 HSV 的阈值范围，被误认为是背景。
· 改进思路：在 inRange 生成掩膜后，增大了形态学闭运算的核尺寸（改为 11x11）。闭运算有效填补了中心孔洞，使得寻找外轮廓（findContours）时，目标更加饱满完整，外接矩形也更精准。

失败案例 2：背景纸盒边缘导致的“误检”

· 现象：画框结果图（result.png）中，除了 6 块橘子果肉，背景纸盒的黄褐色边缘也被画上了绿色矩形框。
· 原因分析：纸盒边缘的 H 值恰好在橙色范围内，且连通面积超过了设定的 1000 阈值，导致被错误识别为目标。
· 改进思路（长宽比过滤）：观察发现，橘子横截面接近正圆形（长宽比接近 1:1），而纸盒边缘呈细长条形。因此在代码中加入了形状过滤逻辑：计算外接矩形的宽高比 aspect_ratio = float(w) / h，如果 aspect_ratio < 0.5 或 > 2.0，则直接跳过，不画框。加入该逻辑后，成功剔除了背景纸盒的干扰，实现准确识别。
